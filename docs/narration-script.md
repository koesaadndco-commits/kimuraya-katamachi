# ナレーション台本（正本）

このファイルが、ホームの「物語を聴く」用 `public/img/narration.mp3` と、オープニング記念映像 `public/img/film.mp4` の音声トラックの**唯一の正しい台本**です。

## ルール

- ナレーション音声を変更するときは、**必ずこのファイルを先に編集してから**音声を生成し直す
- 音声ファイルだけを直接差し替えない（台本とズレる原因になるため）
- 数字・読み間違えやすい語には読み仮名を付ける（TTSの誤読防止）
- 修正は読んで確認できるので、音声を聞き直す必要はない

## 現在の台本（v3 — 2026-10-26 映像とあわせて再生成）

v2 の台本（文面）はそのまま。音声を 1 行ずつ別々に生成し直し、**記念映像の音声トラックにも同じ音声を入れた**（v2 までは映像の中に古い音声が残っていた）。

- 生成：Higgsfield `seed_audio`、プリセット音声「太郎」、speech_rate -15、1行ずつ生成（各 0.1 クレジット）
- 誤読対策：TTS に渡す文面では「昭和**よんじゅうねん**」「**うりば**」「**はちじゅうねん**」「**きむらや**」を仮名で指定している（表示用の字幕は漢字のまま）
- 各行の先頭・末尾の無音をカットし、音量をそろえている（loudnorm I=-19）
- `narration.mp3`：1→6 の順に 0.6 秒の間を空けて連結（33.7 秒）。字幕の切り替え時刻は `public/kimura.js` の `cues` に秒で書いてある：0 / 3.97 / 10.12 / 14.64 / 21.69 / 27.68
- `film.mp4`：映像は元のまま（終わりのタイトルカードだけ 1.5 秒延長して 41.1 秒）。音声トラックを下の配置で差し替えた
