# ナレーション台本（正本）

このファイルが、ホームの「物語を聴く」用 `public/img/narration.mp3` と、オープニング記念映像 `public/img/film.mp4` の音声トラックの**唯一の正しい台本**です。

## ルール

- ナレーション音声を変更するときは、**必ずこのファイルを先に編集してから**音声を生成し直す
- 音声ファイルだけを直接差し替えない（台本とズレる原因になるため）
- 数字・読み間違えやすい語には読み仮名を付ける（TTSの誤読防止）
- 修正は読んで確認できるので、音声を聞き直す必要はない

### 記念映像（film.mp4）のナレーション配置

映像のシーンに合わせるため、映像の中では 3 行目と 4 行目の順番を入れ替えている。

| 開始（秒） | シーン | 行 |
|---|---|---|
| 2.2 | 昭和二十一年 福井市（木村屋） | 1 昭和二十一年、福井。 |
| 5.55 | 同上 | 2 小さな食料品店の木村屋から、すべては始まりました。 |
| 12.5 | 昭和四十年 片町フードセンター | 4 昭和四十年には、片町フードセンターとして歩みはじめました。 |
| 20.3 | 令和八年 午前六時 ハニー食彩館 | 3 毎朝、誰よりも早く売り場に立つ。 |
| 27.9 | 福井市内 ある家族の夕食 | 5 あの日の「いらっしゃい」から、今日の「ありがとう」まで。 |
| 34.2 | ありがとうの、八十年。 | 6 八十年たった今も、私たちは、この町の台所です。 |

作り直す手順（スクリプト化済み。1 行ずつの音声 l1〜l6 を置いたフォルダを渡すと、無音カット・音量合わせ・映像への載せ替え・narration.mp3 と字幕時刻の算出まで行う）：

```
ffmpeg -i l1.wav … → 無音カット＋loudnorm → t1..t6.wav
adelay 2200/5550/12500/20300/27900/34200 ms（上の表の順）→ amix → film.mp4 の音声トラックへ
t1..t6 を 0.6 秒間隔で concat → narration.mp3、各行の開始秒 → kimura.js の cues
```

要点：1 行ずつ生成した音声を `ffmpeg` の `adelay` で上の秒数に置き、`amix` で 1 本にして映像に `-c:v copy` で載せ替える。
