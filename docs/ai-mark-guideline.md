# AI使用マーク 表示ガイドライン

AIを使って制作したもの（Webサイト・動画・チラシ・ポスター・SNS投稿・資料など）には、**すべてこの「AI使用マーク」を表示する。**
このファイルは、制作者（人・AIエージェントどちらも）がそのまま従えるように書いている。

---

## 1. 基本ルール（必ず守る）

| 項目 | ルール |
|---|---|
| **表示位置** | **画面・紙面の左下**に置く |
| **表示する範囲** | AIを一部でも使った制作物すべて（写真・イラスト・文章・映像・音声のどれか一つでも） |
| **添える文章** | マークの右隣に「本サイト（本作品）の一部にAIを使用しています」を添える |
| **ほかの表示との関係** | 著作権表記（©）やクレジット（Produced by …）は**右下**に置き、マークと分ける |
| **加工** | マークの形・文字・色の組み合わせを変えない。縦横比を変えない。回転・影の追加・切り抜きをしない |

---

## 2. 媒体ごとの置き方

### Webサイト
- **全ページ共通のフッターの左下**に、マーク＋文章を置く（右下は © とクレジット）。
- **オープニング画面・トップの最初の画面がある場合は、その画面の左下にも置く。**
- 大きさ：フッターは横 **96px**、オープニングは横 **90〜130px**（画面幅に合わせて可変）。
- 画面の端から **14〜32px** 内側に置く。スマホでは文章を2〜3行に折り返してよい。
- 画像には代替テキスト `alt="AI使用マーク"` を付ける。

### 動画
- **最初と最後の数秒（目安3秒以上）、画面の左下**に表示する。全編に出し続けてもよい。
- 大きさ：画面の高さの **8〜12%** 程度。端から画面の高さの **3%** 以上離す。
- 字幕と重なる場合は、字幕を上にずらす（マークは左下から動かさない）。

### 印刷物（チラシ・ポスター・パンフレット）
- **紙面の左下**、仕上がり線（断ち切り）から **5mm以上** 内側に置く。
- 最小サイズ：横 **20mm**（装飾フレーム版）、直径 **12mm**（丸い版）。これより小さくすると文字がつぶれる。
- 大判（A2以上）は装飾フレーム版を使う。

### SNS投稿・バナー・資料（スライド）
- **画像・スライドの左下**に置く。
- スライドは**表紙と最後のページ**に必ず入れる（全ページに入れてもよい）。

---

## 3. どの版・どの色を使うか

### 版の使い分け
| 版 | 使う場所 | ファイル |
|---|---|---|
| **装飾フレーム版**（唐草のラベル風） | ふつうはこちら。Webのフッター・オープニング、ポスター、動画 | `ai-mark-ornate-{色}[-en].png`（横1400px・背景透過）、Web用の軽量版 `ai-mark-ornate-{色}-sm.webp`（横360px） |
| **丸い版**（スタンプ風） | とても小さく置く場所（横60px未満、直径12〜20mmの印刷）、アイコン | `ai-mark-{色}[-en].png`（1024×1024・背景透過）、`ai-mark-{色}[-en].svg` |

### 色の選び方（背景に合わせる）
| 背景 | 使う色 |
|---|---|
| 紺・黒など暗い背景 | **gold**（金）。白黒にしたいときは **white** |
| 白・生成りなど明るい背景 | **navy**（紺）。白黒印刷は **black** |
| 写真の上 | 写真の明るい部分なら navy、暗い部分なら gold／white。読みにくければマークの下に半透明の座布団（背景色の70%程度）を敷く |

### 言語
- 日本語向け：リボン文字「一部にAIを使用」（ファイル名に `-en` が無いもの）
- 英語・海外向け：リボン文字「PARTLY AI-MADE」（ファイル名が `-en`）

---

## 4. やってはいけないこと

- 左下以外に置く（右下・中央など）。※どうしても左下に置けないレイアウトのときだけ、左上を使う
- マークだけを置いて、文章（「一部にAIを使用しています」）を省く。※動画やSNS画像で文章を入れる場所が無いときは、投稿文・概要欄に書く
- 縦横比の変更、色の入れ替え（例：金の枠に黒い文字）、別の書体への差し替え
- 背景と同化する色の組み合わせ（明るい背景に white、暗い背景に black など）
- 最小サイズより小さく使う
